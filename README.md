## 🚀 How to Use

1. **Open the website**:
   - Simply open `index.html` in any modern web browser
   - Or use a local server for better performance

2. **Customize Content**:
   - Edit `index.html` to update company information
   - Modify contact details (phone, email, address)
   - Update service descriptions

3. **Add Images**:
   - Place your company logo in the `images/` folder
   - Update image references in HTML if needed

4. **Customize Colors**:
   - Edit CSS variables in `styles.css` (lines 10-20)
   - Change primary, secondary, and accent colors

5. **Deploy**:
   - Upload all files to your web hosting service
   - Ensure folder structure is maintained

## 🎨 Customization Guide

### Change Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
    --primary-color: #2563eb;    /* Main brand color */
    --secondary-color: #1e40af;  /* Secondary brand color */
    --accent-color: #3b82f6;     /* Accent color */
}
```

### Update Contact Information
Edit the contact section in `index.html`:
- Phone number
- Email address
- Physical address
- Business hours

### Modify Services
Edit the service cards in `index.html` to add/remove services or change descriptions.

## 📧 Contact Form Integration

The contact form currently shows a success notification. To integrate with a backend:

1. **Option 1 - Email Service (FormSpree, EmailJS)**:
   - Sign up for a service like FormSpree or EmailJS
   - Update the form action or JavaScript code

2. **Option 2 - Custom Backend**:
   - Create a backend API endpoint
   - Update the form submission handler in `js/script.js`

3. **Option 3 - PHP Mail**:
   - Create a PHP file to handle form submissions
   - Update form action to point to the PHP file
